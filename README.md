# Clearline Auto Care

Marketing website for Clearline Auto Care — professional mobile ceramic glass coating service.

## Stack
- Pure HTML/CSS/JS — no framework, no build step
- Single file: `index.html`
- Deploy-ready for Vercel, Netlify, or any static host

## Deploying to Vercel
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → New Project → Import your GitHub repo
3. Vercel auto-detects static — click Deploy
4. Add your custom domain in Vercel → Settings → Domains

## Before going live — swap these in
- [ ] Replace logo text in `<nav>` and `<footer>` with your actual PNG logo file
- [ ] Replace the service area map placeholder with a Google Maps embed
- [ ] Connect "Book a visit" buttons to your booking tool (Calendly / Square Appointments)
- [ ] Update the zip code checker logic with your real service zip codes
- [ ] Replace placeholder testimonials with real customer reviews
- [ ] Add Google Analytics or Plausible tracking snippet
